# Multiple-source demonstrations and actors

Dataset schema3 stores an ordered observation binding in each step's existing `frame` blob: `frames` contains original recording shard/block references, `coverage` contains one original unchanged-source proof or null per frame, and `geometryRevision` is a dataset-local aggregate binding epoch. Source descriptions freeze ordered `surfaceIDs`; the manifest freezes `maximumFrameAgeMs:250`. Each native surface keeps its own geometry revision, frame identity, source time, availability time and pixels. Any change to the ordered geometry vector starts a recurrent episode. Dataset readers retain schema1/2 behavior for existing immutable revisions and exact resume.

Construction independently advances the frame stream and unchanged-source proof stream to the observation cutoff. Every required role must have a causal frame. Ordinary frames age from source time; static frames need a matching proof that arrived by the cutoff, and age from that proof's source horizon. Missing, stale or ambiguous sources fail the complete revision. No frame is silently discarded to make an observation fit. Explicit selected ranges remain strict. A default selection without a supplied start begins at the latest first availability across required roles; a visible warning reports the excluded prefix and physical-event count, and the immutable selection stores the actual start.

Physical pointer labels prefer the recorded exact `surfaceID` hint. A supplied hint must name a containing observed surface; it never falls back to another target. Without a hint, containment must identify exactly one source. Motion simplification preserves source transitions. An ambiguous initial pointer still constrains curve fitting and control features, but its redundant synthetic zero-offset move is omitted instead of receiving a guessed route; real events retain their original times and must resolve their own targets. Batches of sessions with different source counts keep per-session role order and mask absent trailing slots; missing required sources inside one recording are never treated as batch padding. Dense pointing labels retain their actual source slot and source-local coordinates.

Actors accept optional `additionalRings:[{path,ringID}]` alongside the original `ring`. The prepared response includes ordered `ringIDs` and retains `ringID` for the primary mapping. Frames choose their prepared reader by `ringID`; original frame-list order defines observation roles. Partial preparation closes all mappings already opened, and actor close joins every reader. Per-source native ring capacities avoid allocating every slot to the largest source. Optional native window/display identities are included in the agreed `ASTRAN01` fingerprint suffix, while descriptors without these fields retain legacy fingerprint bytes.
