# Native desktop learner publication

This increment connects immutable desktop collection output to the existing native learning owner. It is a component integration, not completion of the live desktop workflow or a release qualification.

`LearningCoordinator.prepareDesktopPolicy` either creates and catalogs fresh local weights or integrity-inspects a linked checkpoint. Inspection uses the checkpoint's model/action contract; unrelated fresh-model defaults cannot change it. Preparation creates no fictitious completed training run.

`DesktopLearningConfiguration` binds an immutable reward/reset definition to the verified live surfaces. The original definition and its fingerprints remain independent of transient window IDs. Its environment-neutral compute specification uses the checkpoint's timing and capabilities. Resume retains the saved task identity, contexts and authenticated checkpoint training configuration, and rejects a changed reward/reset/model contract. `DesktopResetObservations` supplies actual retained frame evidence and serial detector reads to the native reset driver. Repeated pixels may reuse detector output, but source times remain unchanged and readings are recomputed for a new episode.

`DesktopLearningBatch` requires a sealed, eligible collector package, matching policy/run/clock/source identities, real sampled actor progress and the original native producer/control join proofs. A no-draw reset does not manufacture a new sampled cursor. The held `PolicyActorLearningPause` must match that batch; the session excludes predictions, warmup and resets until its current owner releases the pause. Shutdown invalidates the token.

`LearningCoordinator.updateExternal` reuses the existing compute job transport, cancellation, durable run metadata and checkpoint catalog. Every update uses a new compute job run ID, distinct from the persistent actor run. It sends `job.externalBoundary` only in response to the correctly correlated waiting phase, revalidates the held actor boundary, and joins/validates the acknowledgement before publishing the result. Early progress and terminal messages are supported. Published metadata must match the parent checkpoint, sealed rollout, final actor progress and boundary collection. A cancelled update can publish only the worker's explicitly resumable, rolled-back result with the same joined proof. Missing publication never appears as successful training.

The external Python worker now includes the actual model parameter count in its checkpoint result, as required by native catalog publication. Integration tests also exposed and fixed a Swift exclusivity crash in observable run-progress updates and a file-URL directory normalization mismatch.
